#Практическая работа 1

    Для задачи под номером 5 в Scratch реализовал анимацию:
    - прохождения исполнителем по последовательности и прибавления каждого элемента к реальной сумме
    - Далее для последовательности по формуле рассчитывается сумма элементов последовательности по формуле n(n+1)/2
    Тем самым получается, что суммы будут отличаться как раз на искомое недостающее число j;
    - Значит разница теоретической и реальной сумм будет равна j.
