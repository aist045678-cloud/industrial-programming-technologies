## Ход работы

В рамках практического задания №3 необходимо было выбрать две задачи из десяти предложенных и реализовать их несколькими способами. Для выполнения были выбраны **задачи №5 и №7**.

Основная цель работы — изучить различия между подходами к организации программного кода, а также закрепить навыки разработки программ на языке программирования в разных стилях.

Для каждой выбранной задачи было подготовлено по четыре варианта решения:

- Процедурный вариант — вся логика программы реализована последовательно в одном файле. Ввод данных, обработка и вывод результата находятся в основной части программы без выделения отдельных пользовательских функций или классов.
- Функциональный вариант — программа разделена на отдельные функции. Каждая функция выполняет конкретную задачу: получает входные данные, выполняет необходимые вычисления или обработку и возвращает результат.
- Объектно-ориентированный вариант — решение построено с использованием классов и объектов. Основные данные и методы их обработки объединены в классах, что делает структуру программы более организованной и удобной для расширения.
- Многомодульный вариант — программа разделена на несколько файлов. Отдельные модули содержат основную логику, вспомогательные функции или классы, а главный файл отвечает за запуск программы и взаимодействие между компонентами.

        Решение многомодульным вариантом вызвало наибольшее число проблем. На данный момент их решение находится в разработке.
